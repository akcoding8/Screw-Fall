# Changelog

## 1.0.0 — Initial hosted release

- Endless deterministic normal towers, flowing tenth levels and British milestones every hundred levels.
- Difficulty-weighted points, continuous no-death scores and personal records.
- Twenty Standard skins and seven Premium skins, bought with points earned in play.
- Soft, Vivid and Mixed palettes, original procedural effects and synthesised audio.
- Device-local progress, settings and screenshot evidence, with optional starting-level history.
- Offline PWA support after a complete online load, plus iPhone/iPad Home Screen installation.
- Safe, player-controlled updates, install help and public-link sharing in Settings.
- GitHub Pages build and deployment workflow.

Deployment and physical-device acceptance are completed separately using the release checklist.
