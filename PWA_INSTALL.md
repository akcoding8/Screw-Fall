# Install Screw Fall

You can play in a browser without installing. Use the deployed HTTPS URL for Home Screen installation; the development Mac is not needed once the hosted game is cached.

## iPhone and iPad

1. Open the deployed Screw Fall URL in Safari.
2. Keep it online until the first complete load finishes and Settings reports that offline play is ready.
3. Open the **Share** menu and choose **Add to Home Screen**. If **Open as Web App** is offered, leave it enabled.
4. Confirm the name **Screw Fall**, then choose **Add**.
5. Open the new Home Screen icon. Confirm the normal Safari toolbar is absent and Settings reports **Installed**.
6. Play at least one level online, allowing any first-install caching in that app to complete.
7. Close the app, enable Airplane Mode and ensure Wi-Fi is off.
8. Reopen from the Home Screen. Check gameplay, audio, skins and saved progress; open an existing evidence screenshot if you have one.

Apple's [Home Screen web-app instructions](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios) describe the Safari menu. Its position can vary with the device and Safari layout.

Keep the phone/tablet in portrait orientation for play. Reconnect periodically to receive updates. An update waits for a safe state and offers **Restart now** or **Later**; a dismissed update remains in Settings as **Update now**. There is no forced restart in the middle of a level.

## Other supported browsers

If the browser exposes an installation prompt, Settings offers **Install**. The prompt opens only after you press that button. A dismissal leaves browser play available. If no button is available, use that browser's own installation controls where supported.

## Remove or reinstall

Use the operating system's normal Home Screen app/icon removal action to remove Screw Fall. To install again, open the same public URL online and repeat the steps above. Do not rely on removal/reinstallation preserving data: behaviour varies by browser and operating system.

Clearing browser/site data removes local progress and screenshot evidence. Cached offline files may also be evicted by the browser, in which case reopen online to cache the game again. There is no cloud backup or cross-device sync.

The hosted version begins with its own device-local data; development progress does not automatically transfer. You can enter a starting level in **Settings → Progress → Continue from another game**. This does not transfer points, scores, skins or screenshots. Future updates preserve the hosted save through the normal save loader.
